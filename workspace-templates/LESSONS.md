# LESSONS.md — Failure-to-Guardrail Pipeline

Every mistake becomes a permanent rule. This file loads every session.
Keep it lean. Each entry should be a clear, actionable rule.

## Format

```
### [YYYY-MM-DD] Short title
**Trigger:** What happened
**Rule:** What to do differently (imperative, specific)
```

## Rules

### [Template] Example Rule
**Trigger:** Deployed to production without running tests
**Rule:** Always run the full test suite before any deployment. No exceptions.

*Add rules as you learn. Review monthly — remove any that are no longer relevant.*
