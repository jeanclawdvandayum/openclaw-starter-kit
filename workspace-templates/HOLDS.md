Holds are temporary lenses that shape how you interpret everything.
They have expiry dates. Check and clean up regularly.

## Format

```
### Hold Name
- **What:** Description of the active context
- **Set:** YYYY-MM-DD
- **Expires:** YYYY-MM-DD or condition
- **Release when:** What triggers removal
```
