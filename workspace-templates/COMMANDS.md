# COMMANDS.md — Vault Commands

When your human sends a `/command`, execute it against the vault (your files).

## Daily Operations

### /context
Show current working context: active projects, recent decisions, open questions.

### /today
Create or update today's daily note (`memory/YYYY-MM-DD.md`).

### /close-day
End-of-day review: summarize what happened, extract insights, update topics.

### /7plan
Review the week ahead: deadlines, goals, blockers.

## Knowledge Graph

### /map
Show the knowledge graph index (`memory/_index.md`) with topic counts.

### /bloom [topic]
Expand a topic file with new connections, related ideas, or deeper detail.

### /backlinks [topic]
Find all files that reference a given topic.

### /graduate
Review recent daily notes for recurring themes ready to become topic files.

## Thinking Tools

### /trace [concept]
Follow a concept through the knowledge graph — where does it lead?

### /emerge
Look for patterns across recent work that haven't been named yet.

### /connect [A] [B]
Find non-obvious connections between two topics.

### /contradict [claim]
Argue against a claim or decision. Steel-man the opposition.

### /drift
Compare current direction against stated goals. Are we drifting?

### /challenge [assumption]
Question a foundational assumption. What if it's wrong?

## Perspective Shifts

### /ghost
What would a fresh agent think looking at our files? What's confusing?

### /stranger
Read recent work as if from an outsider's perspective. What's unclear?

## Content Creation

### /ideas
Generate project or content ideas based on recent context.

### /learned
What have we learned recently that's worth sharing?

### /weekly-learnings
Compile the week's insights into a shareable format.

### /xdaily
Cross-reference today's work with the broader knowledge graph.
